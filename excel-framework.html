Excel EDA Framework

Python + xlwings + VBA automation for Exploratory Data Analysis directly in Excel

View Code

Overview

This framework automates univariate EDA for both qualitative and quantitative variables, generating formatted tables and VBA-triggered charts directly in Excel.

Key Features

Auto Table Generation

Frequency distributions, percentages, and summary statistics.

VBA Integration

Dynamic charts created via macro.

Excel Native

Results stay in Excel tables, fully editable.

Demo

Installation

  1. git clone https://github.com/LuizStefanuto/excel-eda-framework
  2. pip install -r requirements.txt
  3. Open analysis.xlsm
  4. Run main_analysis.py

Usage

quali_tables = fx.create_count_tables(data_df, quali_vars)
fx.write_table_grid_xlwings(quali_tables, "Análise_Exploratória_Quali")
my_macro('Análise_Exploratória_Quali', my_criteria)
